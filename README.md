# Edited-Media
This is a repo where I edit different kinds of media for a person I know with mental issues preventing them from seeing certain stuff without feeling bad. Hope putting it on GitHub will also help anyone else.

Most of the files can be directly copied onto original, like in case of games you can put files obtained here onto downloaded version of games on steam. If anything would need any other way it will be mentioned into info file in the media folder. And for those who gonna ask, yes this probably would work on pirated copies since those are just changed game files but, I neither condone piracy nor used any pirated media for making this project.

I'm also adding simple bash files of many media that is already alright to not see achievements, community and such on steam launcher which I cannot edit.

Most of the stuff is edited to contain less graphic stuff, less violence, no *isms or insults, but many changes are very specific stuff that my friend requested. I will probably not add any files from anybody, but if you wish feel free to either make another branch (which I actually might merge honestly) or put your problems, reccomendations to edit and such into the repo issues. I will also use branches for specific games probably so feel free to check them out for upcoming media.

Some media might be incomplete or not done at all when mentioned on the list because I'm pretty sure adding unchanged game files and such will lead to copyright issues. I'm myself sometimes use and work with decompiled copies and such but I only use legally obtained copies of any media here. I will also try to include guides on decompilation of certain media and assets to replace in them for anyone who want to use those in places where I can't redistribute original files.

This repo is primarly for Linux and that is why I use shell scripts but most games should work on any system since its majorly just file swap.

Since I will add media from all over places and different kinds of it, I will include short name or note in list to know what version specifically it is for.
