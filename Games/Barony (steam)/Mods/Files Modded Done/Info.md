Mods were downloaded and setup on October 17 2026. Some files might be shared between mods due to them changing same files. All the mods here are also checked the same way as regular barony files from this project. The mods were tested on linux version of the game.
To apply mods onto your instance just copy and replace files in main game folder with chosed mod files after applying previous patch.
You can also put it in your local mod folder to control it through the game itself.
Mod directories are:
```
Linux/SteamOS
$HOME/.barony/mods/MODPACK_NAME

Windows - Not checked.
BARONY_FILES_FOLDER\mods\MODPACK_NAME

MacOS
???
```
