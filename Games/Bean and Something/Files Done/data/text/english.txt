Tile mode

Use left click to place tiles, and right click to remove them. Hold shift and drag to place a large rectangle of tiles.

------------------

Object mode

Place objects in the puzzle. When certain objects are selected, a properties panel will appear in the sidebar. This lets you change the bean type associated with an object, or the initial state (open/closed) of a door or forcefield, etc.

------------------

Edit mode

This lets you save and test the puzzle, as well as change its name, difficulty, or recipes.

You can select both objects and tiles together while in this mode (so if you need to reorient a section of the puzzle, turn on edit mode).]]
